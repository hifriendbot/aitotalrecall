# Changelog

## 0.2.0 (2026-10-29)

First public release.

- Pane with Recalled, Learned and Rules tabs, expandable rows with copy, ask, related and close
- Memory search box in the pane and `/recall find <query>`, no model turn, no tokens
- Band above the prompt with live counts, a per-turn activity pulse and the last event
- Transcript cards for every memory call, replacing raw JSON
- Toast on each save, status line counts, lifetime counters across sessions
- Setup card and band notice when no memory server is connected
- `/recall` and `/aitotalrecall` commands with `hide`, `show`, `clear`, `setup`
